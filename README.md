# EduGrove-Student Resource Hub
EduGrove is a comprehensive student resource website designed to empower learners with access to academic tools, tutorials, and opportunities. Built with HTML, CSS, JavaScript, Bootstrap, and Firebase, EduGrove offers an interactive and user-friendly platform that supports students in every stage of their academic journey.

Features
User & Admin Authentication using Firebase
Integrated Chatbot – Provides instant answers, navigation help, and support to users
Courses Section covering Full Stack Development, AI, UI/UX, and more
Upcoming Events managed by admins, visible to all users
Competitive Exams guidance (GATE, GRE, CAT, IES, DRDO, etc.)
Aptitude Resources and ATS-friendly resume templates
Feedback sections for better support and interaction
Profile Icon Dropdown for login access (User/Admin)

Chatbot Highlights
Instantly answers frequently asked questions
Provides course and event recommendations
Helps navigate different sections of the site
Engages users for an interactive experience

Tech Stack
Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
Authentication & Database: Firebase
Deployment: GitHub Pages / Firebase Hosting

Goal
To provide a centralized platform for students to access curated content, improve skills, and stay updated on career opportunities.
